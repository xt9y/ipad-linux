## 4. Established static picture — the SMC boot-object chain (this is the core context)

**Address model.** For the SMC band `[0x1a5bb8..0x28a640]` (image-relative), SMC-VA = `0x1FC000000 + image offset`. Literal-pool census: 16,029 qwords are SMC-domain pointers in exactly that band; staging/service zone `[0x1a5bb8..0x1f64a0)`, decoded SMC image anchor at `≈0x1f64a0` (+0x79760 B, content-verified via RTKSTACK guard pages and driver strings), beyond-file SMC heap/stack `[0x2269d8..0x28a640]`. Fixed shared base `0x1a5bb8 → 0x1FC1A5BB8` recurs in every `0x194000..0x1945a8` descriptor group.

**Dispatch tables (pool).** `{0x8010b803|kernel}` = table A (11 kernels `0x140ca0..0x140f60`); `{0x801023ca|kernel}` = table B (11 kernels `0x145adc..0x145c1c`, idx 255 is re-signed `{0x807023ca|0x145b18}`); `{0x80XX0000|low}` class-tagged records, 94% pointing into iBoot's own code band (`0x1316d8`, `0x1351d4`, `0x133cfc`, `0x157f6c`, …) plus the `0x151000..0x158000` service band.

**Boot-object registry.** `0x207c8..0x20b00` allocates linked-list objects; the img4 constructor `0x20994` writes `0x696d6734` at `+0x70` + size `+0x74`, links `+0x40..+0x60`, ranges `+0x78`/`+0x88`. `0x8205c` builds the other type `0x4d656d7a` ("Memz" BE) at `+0x08` with u32s `+0x04`/`+0x0c` and five pointers `+0x10..+0x2f`. **Early flow, function `0x37188` (boot-object manager).** Gates: `bl 0x4285c` with `w0 & 0xffff` keyed `< 0x100`; feature-flag read at `0x23d2d0010`; `0x426bc`/`0x428cc` bit-8 checks; incoming `x19` object cleanup via `0x3cc60`.
