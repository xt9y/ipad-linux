## 2. What H5 is

The SPTM's own call-word router: the kernel-side dispatcher that
consumes `(domain << 32) | (flags << 6) | endpoint` call words against
a per-cpu dispatch-table registry and transfers to handler functions.
Per the harness-spec H5 charter: decode the router from real bytes,
then classify its input-accepting surface by direct emulation drives
with a synthetic post-boot sandbox (synthesized registry slots,
dispatch tables, per-cpu context block — correctness/robustness
research on the kernel's own arg discipline, no shellcode and no
state-bypass: every handler body runs in-blob or is a labeled
boundary).

## 3. Router decode (byte-verified semantics)

Call word: bits[39:32] = domain, bits[7:6] = flags (must be 0 for the
fast path), bits[5:0] = endpoint. Flow:

1. `mrs x11, s3_6_c15_c11_1` (per-cpu context register; 230 sites
   image-wide) — sandbox primes a synthetic 64 KiB ctx block.
2. Registry: slot = `registry_base + (domain & 0xff) * 0x10`, layout
   `{table_ptr, stamp}` (+0/+8). The router loads the stamp, copies it
   to ctx+0xb08, and — **the router never checks the stamp** — then
   loads the table pointer.
3. Unregistered/null-table/null-entry arms: `cbz` arms at fo
   0xe4c70/0xe4c84 target the shared unknown-arm block at fo 0xe4cd4;
   the flags-nonzero arm (`tst x0,#0xc0; b.ne`) targets fo 0xe4d48.
   Both arms converge on the same diagnostic: domain-name table loads
   (fo 0x1aeb0), two prep calls, and construct of the shared reporter
   call `mov w0, #0x31 / #0x62 / #0x70; bl 0xf5a60`.
4. Cpu-state gates off ctx+0xb30 (panic-state byte):
   - state 0x16 and row-flag bit0 clear → tier-0x62 arm (fo 0xe4e60;
     reporter bl at fo 0xe4ed8);
   - state 0x14 and row-flag bit1 clear → tier-0x70 arm (fo 0xe4dcc;
     reporter bl at fo 0xe4e3c);
   - otherwise → ok-arm fo 0xe4ca8: `mov x0, x8` (handler word), a
     PAC-frame restore ending in store/x30-auth tombstone: a tail-b to
     the transfer fn (fo 0xe4cd0 → 0xa2430), guarded by an
     anti-tamper check `eor x16, x30, x30, lsl #1; tbz x16, #0x3e`
     (x30 bit62 == bit63) else `brk #0xc471` at fo 0xe4ccc (word
     `0xd4388e20`; BRK imm16 lives at bits[20:5]).
5. Transfer fn (fo 0xa2430): loads the **verb argument file** — the
   handler's x0..x7 — from ctx+0xb40..0xbf (not from the router's
   x0!); selects a DAIF mask either `0x3c0` (when the w1 flag set =
   counter-derived urgency path) or from ctx+0x130/0x1b0/0x2b0
   selected by `(ctx+0xb38 − 1) ∈ {0,1,2}`; `msr daif` + immediate
   mask; then `blraaz x11` = the single PAC'd indirect call site into
   the handler. On handler return the shim **writes x0..x7 back into
   ctx+0xb40** — args and results transit the per-cpu context block.

## 4. Registry static state (finding — blob ships pre-wired tables)

The registrar (`fo 0xe4b1c`) rejects domain > 0x13, boot-complete
(bit7 of the boot flag at fo 0x106040), and double registration
(slot table word != 0). A "registry is all-zero in the blob" model —
held by the interim ledgers — was wrong. Real static state (byte dump):

| slot | table word | stamp | shape |
|---|---|---|---|
| dom 0 | {0x00200000 \| 0x1dbf0} | 0x00 | tagged table record → catalog head region |
| dom 1 | {0x00200000 \| 0x1e1f0} | 0x00 | same-tag record |
| dom 2 | {0x01000000 \| 0x1e7f0} | 0x00 | different tag |
| dom 10 | {0x01500000 \| 0x1edf0} | 0x00 | different tag |
| dom 3..9, 11..19 | 0 | 0 | zero slots |

The tag field is a **band selector**, not a pending pointer: record
words resolve as `{tag|off32}` → VA `(tag << 32) + off32`, with
off32 = an in-image byte offset and each used tag's band mapped
byte-identically to the image copy (the sandbox maps all 36
statically occurring bands). Through that resolution the dom-0
pre-wired table's endpoint-1 row is the FID-catalog LOCKDOWN fn
record `{0x80200000 | 0xeb534}` with flags byte 0 — i.e. the blob
ships a resolvable core dispatch table, not an uninitialized registry.
Slots 11..19 are zero, so the registrar's double-registration reject
and the unregistered-domain arm both have live semantics for those
domains only. Region beyond dom ~20 (fo 0x99fa8+) is a different
constant pool (0xACCE55ED canary markers, string refs) — the
256-slot framing from later Ghidra notes overshoots: the registrar's
own bound is dom ≤ 0x13.

Class-level consequence: the "unregistered domain" arm in the blob's
shipped state fires for freshly-allocated domains (e.g. the emulated
dom 6), not for the four pre-wired ones.

## 5. Word-record surface (ecosystem-wide shape, byte-verified)

Three record-word families appear image-wide (486/109/28 leading uses
of tags 0x00100000/0x80200000/0x00200000): string-name records,
function records, and table records, all `{tag | off32}` with the
off32 = file offset. The FID catalog (fo 0x1dbe0) is a 0x18-stride
`{name-rec, fn-rec, zero}` chain consistent with that family. The
router consumes table/handler words through the band resolution
(§4), so record-grammar correctness is a load-bearing invariant for
the whole verb path — treat any handler-side producer of record words
as in-scope for the same shape checks as the ep0/iBoot records (H4:
{tag|low32} chains there resolve `base + low32`; here the tag band
scheme adds the selector semantic).

## 6. System-register surface (sandbox model, counted)

Image-wide MRS census (capstone strict sweep, skipdata): s3_6_c15_c11_1
230 sites, s3_6_c15_c8_0 176, tpidr_el2 159, tpidrro_el0 94, plus a
long tail of standard EL1/EL2 regs and s3_0/s3_3/s3_4 Apple families.
The harness models the four families above (all sites byte-matched;
230+176+159+94 = 659 hooked reads) and documents the rest as the
boundary: any wave path that would read an unmodeled family stops with
a recorded unhandled-instruction error, which is honest classification
data, not a hidden assumption. The transfer fn's `msr daif` /
`daifset` immediate writes are standard ARM state and supported by the
emulator (verified: all 9 transfer-completing runs crossed them).

## 7. Emulation waves and results (22 runs, exit 0)

Sandbox: synthetic slot dom 5 → synthetic table, stamps boot-set,
pre-wired record slots preserved from the blob bytes, ctx fields
synthesized per §3 (type=1, panics state/count/arg-file primed), 2 MiB
instruction cap, runtime sig-anchors in every run.

- **W1 row-flag conformance matrix (12 runs)**: 4 flag values × 3 ctx
  states. Every run matched the byte model: tier-0x62 at state 0x16
  with row bit0 clear (2 runs), tier-0x70 at state 0x14 with row bit1
  clear (2 runs — note state 0x14 + bit1 set still transfers), all
  remaining rows (8) transfer and reach the handler shim via the pac'd
  indirect call (`transfer-to-stub(ok)`: x0 = 0x2a from the
  sandbox ret-stub, run returns cleanly).
- **W2 unregistered domains (2 runs)**: dom 6 (clean zero slot) →
  `tier-0x31(unknown-arm)`; dom 0 (pre-wired tagged record) →
  `transfer-to-realfn` with the LOCKDOWN fn head executed — i.e. a
  verb aimed at the blob's pre-wired core table reaches its shipped
  handler, flags 0. No rejected domain expects a null-table transient
  state in the shipped blob.
- **W3 null-row endpoint (1 run)**: registered table, unprimed
  endpoint row (row word 0) → `tier-0x31(unknown-arm)` — the shared
  arm also serves the null-entry class, as the byte flow predicted
  (two distinct cbz arms converge there).
- **W4 call-word flags set (3 runs)**: bits 6/7 (values 0x40/0x80/0xC0)
  → `tier-0x31(flags-arm)` — flags-bits-set calls are rejected at the
  entry gate itself, no table reach.
- **W5 real-fn handler reach (2 runs)**: LOCKDOWN (fn fo 0xeb534) and
  MAP_PAGE (fn fo 0xed5a8) rows built into the sandbox table: both
  transfer and **execute the real handler fn head** (catalog-resolved
  fns are callable through the shim; the handler classes were hit with
  the sandbox zero-arg file, so handler-internal semantics stay
  out-of-scope here).
- **W7 x30 anti-tamper (2 runs)**: x30 bit62 set → `brk #0xc471`
  fires (anti-tamper works as decoded, word `0xd4388e20` verified in
  emu); x30 bit62 clear (0 and even sentinel forms) → tail-b
  transfers normally.

## 8. Boundary classes (labeled walls, not claims)

1. **Diagnostic depth wall**: every run that enters the shared
   unknown-arm/flags-arm diagnostic proceeds through the domain-name
   table loads, prep calls and the `{tag|off32}` string materialization
   (the linker-family SIMD scan fn at fo 0xacd44, whose callers pass
   record words raw), and then terminates at one structured
   read-unmapped inside the sandbox (per-class stack-frame-relative
   pointer, Δ values 0xc0/0x60 across handler classes). The
   wave classes in §7 are all measured at the arm-entry blocks, which
   sit before that wall and are byte-stable. The reporter body
   (fn fo 0xf5a60, `mov w0, K; bl`, K = tier constant) is the shared
   convergence point; its interior (console/event machinery) stays the
   documented boundary — the tier constant selection is fully decoded
   without executing it.
2. **DOM0 pre-wired-table depth**: the LOCKDOWN row resolves to the
   shipped fn; with the sandbox zero-arg file the real handler reaches
   the same diagnostic chain depth as W5. Handler-internal semantics
   (post-zero-arg behavior) not claimed.
3. **Unmodeled sysreg families** (§6): out-of-model reads stop the run
   with a recorded error; none occurred on the §7 paths.

## 9. Findings (class-level)

1. **VA-base correction** (§1): every prior audit-sptm VA name is
   0x4000 high; the corrected base is
   `0xfffffff027004000` (LC_SEGMENT_64). Any future cross-referencing
   of audit-sptm material must go through the correction table.
2. **Registry pre-wired state** (§4): four domains ship boot-time
   tagged table records with stamp 0; the stamp is a
   registrar-visibility field only — the router never reads it. The
   shipped dom-0 table routes endpoint 1 to the LOCKDOWN fn.
3. **Stamp bypass is not required**: the stamp is not part of the
   route check anywhere; its only consumer is the registrar's
   bookkeeping and the ctx+0xb08 copy. Nothing in the router path
   treats an unstamped slot as invalid — this is a structural
   observation of the router's own discipline (the registrar writes
   table+stamp together at boot; class note only).
4. **The arg-file ABI** (§3.5): handler x0..x7 and return x0..x7
   transit ctx+0xb40..0xbf — the per-cpu context block is the verb
   call ABI's register spill, not incidental scratch. Consumers of
   the ctx block offsets 0xb00/0xb08/0xb30/0xb38/0xb40..0xbf = the
   router+shim pair's full field list (byte-verified).
5. **Flags-bits 6/7 = entry-gate reject** (W4): the call word's
   flags bits are checked before any registry load — a malformed
   call word cannot reach table machinery.
6. **Anti-tamper tombstone** (§3.4/W7): the router's x30
   self-auth check lands on a `brk #0xc471` whose immediate encodes
   at bits[20:5] (first-pass model shifted it — caught by the
   harness's own runtime sig-check, corrected in the committed
   ledger).
7. **Uniform reject discipline holds for the fast path**: across 22
   runs no input-reachable path produced an emulation-visible memory
   safety deviation inside the router/shim itself; every deviation
   observed was the sandbox's own unmodeled region (labeled §8).
